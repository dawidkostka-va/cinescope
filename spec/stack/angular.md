The workspace is an Nx 23 monorepo. The application is the Nx project `cinescope-angular` in
`apps/cinescope-angular`, generated with the Nx Angular application generator: **Angular 22**,
standalone components, zoneless, Angular Router with an empty route list, SCSS, Vitest for
unit tests and ESLint. **Angular Material 22** and the Angular CDK are installed, a Material
theme is applied in `styles.scss`, and the native date adapter is provided for the
datepicker. It is ready to run; build the application on top of it.
