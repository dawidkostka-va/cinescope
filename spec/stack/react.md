The workspace is an Nx 23 monorepo. The application is the Nx project `cinescope-react` in
`apps/cinescope-react`, generated with the Nx React application generator: **React 19**, Vite,
React Router 6 with a `BrowserRouter` and an empty route list, SCSS, Vitest for unit tests
and ESLint. **MUI 9** (`@mui/material` with `@mui/icons-material`) and **MUI X Date
Pickers** with `dayjs` are installed; `ThemeProvider`, `CssBaseline` and a
`LocalizationProvider` with the dayjs adapter wrap the application. It is ready to run;
build the application on top of it.
